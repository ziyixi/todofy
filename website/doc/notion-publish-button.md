# Notion publish buttons: retired

The public Notion publish/status buttons and Notion status write-back have been removed. Keep the Blog
collection's Draft/Published publication fields. Content sync now runs once daily; use Home's **同步网站**
action when an update is needed sooner.

See the current [release manual](../docs/release.md). Historical feedback properties and buttons may be
removed manually in Notion; this migration does not delete or edit private Notion content.
