# AI / ML 精选发现入口

这是可编辑的公开导航，不是作者、机构或域名白名单，也不证明某篇论文真实、已接收或重要。
每轮围绕一两个具体问题选择少量入口，不必打开所有首页，不增加研究轮次。必须遵守原有搜索、来源、隐私和预算规则。

## 先找具体研究，再核对出处

- [PMLR](https://proceedings.mlr.press/)：机器学习会议与workshop论文集；核对卷名、年份和具体论文，不能把workshop当主会。
- [NeurIPS论文集](https://papers.nips.cc/)：从正式论文及所属轨道找方法、数据、评测研究，不把上一届论文重新标成近期首发。
- [OpenReview](https://openreview.net/)：从ICLR、ICML等官方venue入口找论文和公开决定；仅有投稿页不能写已接收，匿名阶段不猜作者。
- [ACL Anthology](https://aclanthology.org/)：语言与NLP研究；区分会议主集、Findings和workshop，追踪原始方法及评测条件。
- [CVF Open Access](https://openaccess.thecvf.com/CVPR2026)：视觉研究的一个官方届次入口；按实际年份找具体论文，不把页面访问日或会议日当首发日。
- [JMLR](https://www.jmlr.org/papers/)：理论、方法及严肃实证；必要时回看较旧研究，但说明当前意义而不是伪装新进展。
- [CMU机器学习研究组目录](https://www.ml.cmu.edu/research/)：从具体研究者/实验室的论文线索补充非LLM、理论、决策和系统方向；目录不是成果证明。
- [Google DeepMind论文目录](https://deepmind.google/research/publications/)与[Microsoft Research论文目录](https://www.microsoft.com/en-us/research/publications/)：跟进研究团队的原始论文/技术报告；机构博客和厂商自测不是独立验证。

这些入口在2026-09-06按官方页面核对；网站内容、届次和可访问性可能变化。本指引不承诺今天有新论文。
arXiv仍可作为原始稿来源；不要仅凭挂在arXiv判低质，也不凭知名作者判突破。名单之外的新团队同样按下述标准考虑。

## 具体贡献而非题材标签

候选需能用普通语言交接：以前卡在哪里，这次改了哪个机制或提供了哪项新证据，与什么比较，为什么值得读者理解。
方法研究看机制、适用条件、匹配基线及代价；新能力看以前做不到什么以及验证范围；benchmark/失败分析看新揭示的失效模式或对既有结论的实质修正，不把数据量当贡献。
负结果、复现和小团队也可能很有价值；“评测很重要”“安全很重要”只是领域背景，不是这篇论文的入选理由。

authors/affiliations只记录在该研究中可核实的署名与单位；venue/publication_status核对具体出版或接收记录。
contribution保留增量和关键未知；source_basis解释出处线索为何值得查，而不是列名校名人给结论担保。
evidence_urls仅列本轮实际打开、支持上述字段的具体原始页面（最多4个，可含主url）；未核实信息留空。
