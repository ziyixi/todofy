# 科学、能源与产业转变候选发现

发现最多5项非AI/ML的重要变化或少量高增量研究，不凑数。优先能源、材料、制造、生态和科学基础设施从实验到真实应用的进展：产能、成本、许可、可用性和关键瓶颈变化。区分已运行、试点、获批和长期承诺。权威行业调查、原始运营数据和公共机构材料均可作入口，不只搜索论文。

少量真正有新机制或决定性证据的研究仍可竞争研究位置，轮换生命、地球、物理、生态、考古和严肃社会科学。Nature、Science、PNAS及专业期刊可作发现入口，期刊名气不构成结论可信的证明。不为科学栏目凑论文，与AI/ML竞争同一全期研究预算。

每项用短概述解释科学问题、实验/观察/模拟类型、已见结果量级与最重要未知；不要在发现阶段编造未读方法。Crossref及RSS只有元数据，不证明全文可访问、同行评议状态或实验结果。记录DOI、版次、发布日期和实际打开的URL。

把待深读问题写具体：样本/对照、基线、单位、误差和替代解释。适生度不是种群丰度，统计阈值不是生理实测，相关不是因果；训练量和方法同时变化不能全归因于单一因素。近两周优先，窗口外明确回看，不重复已用论文或仅换报道URL。
