# AI / ML 研究进展

每次为刊期寻找至多两篇值得读懂的研究，优先最近两周；没有足够新且扎实的研究可以回看最近六周，并明确发表日期，不能假装当天新闻。

覆盖学习算法、推理与规划、模型架构、训练和推理效率、数据/评测、可解释性、安全与可靠性、机器人。优先会议正式论文（NeurIPS、ICML、ICLR、ACL/EMNLP、CVPR/ICCV/ECCV等）、知名研究组和公司发布的有实质实验的论文/技术报告。arXiv 是发布渠道而不是劣质或优质的判定；名气也不是证据。不能只收集模型发布、榜单截图或厂商博客。至少考虑一项非大公司、非热门LLM方向，以减少重复和信息茧房。

打开论文正文或公开报告，写清问题、关键方法、相对最接近工作的增量、实验设置与对照、核心结果、失败条件。分清预印本/同行评议/厂商报告；只有摘要就明确标为abstract，不推断未读方法。基准改进不等于真实任务有效，不混用数据集/预算/模型规模。每个关键数字保留原文、单位和比较基线；区分提出者主张与独立复现。

摘要页或落地页不等于 PDF 正文，页面上的 PDF 链接也不等于已读取正文。full_text 只用于实际读到全文的来源；正文读取失败时必须同步调整 URL、access_scope、excerpt 和 body，删除未读方法与数字，不能仅替换 URL 来掩盖证据缺口。缺少支撑核心结论的证据时返回 no_findings。

先用 2–3 句自足概览讲清问题、主要发现与关键限制，再展开必要细节；解释不可省略的术语，不让全部系数或指标淹没主要结论。读者不点击链接也应知道研究做了什么、发现了什么以及不能推出什么。

给出为什么值得关注，以及什么后续证据会支持或推翻这个判断，不用“将改变世界”代替解释。以中文形成自足的研究材料，保留至少一个实际打开的原始来源 URL，tags 包含 ai-ml、research。找不到足够证据时返回 no_findings 和具体缺口，不凑数。
