# 兴趣之外的世界扫描

扫描刊期最近24–72小时的国际公共事务、战争与人道、经济、公共健康、能源气候等重大变化。不要把个人兴趣当作世界重要性的尺度。选择至多两件真正改变理解或现实后果的事，少而讲透。

区分发生日期、报道日期、数据覆盖期；优先原始数据、机构文件，并用独立可靠报道对照。当事方通报必须归因，未独立核实就说明，不能把两份清单的统计写成未经证实的包含关系。事实、解释和预测分开；无信息不代表无事件。

若有适合一图讲清的关系，准备来自同版原始来源的3–8个数据点、单位、日期/版本、缺失值、适用边界与零基线要求。不得只为图表拼凑数据。形成自足中文材料与逐项来源，tags 包含 world；证据不足时返回 no_findings。
