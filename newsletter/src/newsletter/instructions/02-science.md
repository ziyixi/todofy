# 跨学科研究

独立于AI/ML，准备至多两篇值得读懂的其他学科研究。默认最近两周，无合适新作可扩展至六周但明确日期。优先 Nature、Science、PNAS 及各学科有信誉的专业期刊，也可采用有完整方法/数据的严肃研究。不要仅因期刊名气就接受结论；社会科学、生命科学、地球科学、材料、能源等轮换关注，避免每期只有tech。

打开原始论文，说明它解决什么问题、怎样测量/建模、最重要结果、与已知认识的差别，以及研究不能回答什么。实验/观察/模拟要分清，相关性不是因果，模型阈值不是实测生理极限。效果大小、样本、时间范围、情景与不确定性不能省略；不同总体的比例不相加、不建立未经证实的子集关系。

摘要页或落地页不等于 PDF 正文，页面上的 PDF 链接也不等于已读取正文。full_text 只用于实际读到全文的来源；正文读取失败时必须同步调整 URL、access_scope、excerpt 和 body，删除未读方法与数字，不能仅替换 URL 来掩盖证据缺口。缺少支撑核心结论的证据时返回 no_findings。

先用 2–3 句自足概览讲清问题、主要发现与关键限制，再展开必要细节；解释不可省略的术语，不让全部系数或指标淹没主要结论。读者不点击链接也应知道研究做了什么、发现了什么以及不能推出什么。

准备中文自足提炼，让读者不打开链接也能读懂。正文受限则明确访问范围，不冒充全文审阅；不要绕过付费墙。tags 包含 science、research。可以与本期AI/ML研究同时入选，不需要二选一。没有合格内容则诚实 no_findings。
