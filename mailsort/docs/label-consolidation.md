# 标签整理与分类效果检查

标签现在使用单层英文名称，Gmail 和 Mailsort 显示相同名称。中文说明、归档开关、可信域、敏感设置继续保留。旧标签在整理前仍可读取；本页不包含任何真实邮箱映射。

## 开始前

1. 在“标签”核对 Gmail 状态。尚未创建、没有 Gmail ID 且没有同名冲突的标签可以参与；已删除或身份不明的标签不能参与。
2. 同一合并组的启用、归档、可信和敏感设置必须一致。第一项是保留的目标，其内部 ID 和已有的 Gmail ID 不变；其他项成为停用的历史身份。
3. 等待正在执行的分类写入、撤销和分类效果检查结束。未排空时页面会拒绝开始，原任务继续运行，完成后再开始。
4. 确认 Gmail 中没有占用旧来源名或最终目标名的外部标签。整理期间避免手工修改相关标签及其邮件归属。

关闭模式、只读授权、运维限制和既有写入预算仍然有效。整理不会自行切换模式、提高额度或重新授权。

## 提交私有计划

打开“设置 → 整理标签”，填写 JSON 数组。以下只是假数据：

```json
[
  {
    "sources": ["项目/构建", "项目/工具"],
    "display_name": "Projects",
    "description": "项目构建、代码评审、开发工具和服务运行通知。"
  },
  {
    "sources": ["旅行通知"],
    "display_name": "Trips"
  }
]
```

- `sources` 填现有完整名称，第一项保留为目标。每个来源只能出现一次。
- `display_name` 最多 40 字符，至少包含一个英文字母；可含数字、空格及 `& ' ( ) . , + _ -`，不含 `/`。
- `description` 可省略，沿用第一项说明；合并组应填写涵盖所有来源的新说明，最多 300 字符。

点击预览，核对来源、目标和说明，再点击开始。界面会解析当前 ID 和 etag；预览后标签被修改则拒绝旧计划。实际映射只写入已鉴权的私人对象，不进入公开代码或日志。

## 运行与恢复

“整理标签”显示核对、改名、转移、验证、隐藏及完成阶段。进度是已处理的标签成员关系数，同一封邮件涉及多个来源时可能计入多次。刷新可读取持久进度，关闭页面不影响 Alarm 继续执行。

- 已有目标直接改 Gmail 标签名称，历史邮件随原 ID 显示新名称。尚未创建的目标只创建最终英文名，保存返回 ID 后再核验。
- 尚未创建的来源没有 Gmail 成员要搬，只合并配置、原例子和可信域；不会为了迁移先创建旧标签。
- 合并只读取邮件 ID、标签集合和 historyId。保存处理进度，再添加目标、移除来源并回读验证。
- 分批处理后重新读取来源的第一页，避免修改集合时分页漏项。不会读取旧邮件正文或重新分类，不改收件箱、已读、星标或其他标签。
- 新邮件继续登记，分类、学习、相关编辑及撤销等待整理完成。任务完成后按届时有效的模式恢复处理。
- 来源搬空后隐藏；旧分组只有在本应用创建、已空且没有无关子标签时才隐藏。标签 ID 保留，不删除 Gmail 标签。

| 页面状态或原因 | 下一步 |
|---|---|
| 已有 Gmail 写入未完成 | 等待原任务结束后重新开始；尚未接受整理任务 |
| 运行中、关闭模式或运维暂停 | 核对当前模式及限制；无需重复提交计划 |
| Gmail 限流、网络错误或暂时故障 | 依赖恢复后点击继续，沿用原任务与进度 |
| 达到每日写入上限 | 下一个 UTC 日再继续；不要为整理提高预算 |
| 名称或标签身份变化、目标名称冲突 | 在 Gmail 核对并恢复计划预期身份后继续，不要删除标签或重建对象 |
| 创建目标后未取得返回 ID | 保留任务并核对创建结果；服务不会仅凭同名标签认领，不能直接重提计划 |
| 邮件标签发生额外变化、来源重新出现 | 保留现场，核对该条迁移与后续人工修改；不要把它当作成功或强制覆盖 |

“继续”带当前任务 etag；旧页面或重复请求不能启动另一个整理。界面明确报错的任务仍保留进度及暂停，不会悄悄跳过未验证的邮件。

## 历史、学习与撤销

原始预测、概率、决策时间和写入账本不改写。报表和回放通过合并映射展示现有分类；例子、可信域保留原学习时间和现有限额，敏感标签不保存例子。整理自己的 Gmail history 不作为人工纠错。

合并来源的旧操作只供查看，不能撤销；不提供反向迁移。整理后的新分类继续使用普通撤销。一对一改名没有改变 Gmail ID，原有撤销行为不变。

## 检查分类效果

设置页的“检查分类效果”读取最近 14 天已经回答的样本，沿用现有回放和模型额度。它不修改 Gmail，也不调整模式、阈值或预算。运行中不能启动新任务覆盖；标签整理期间暂停。

界面展示进度、完成时间、样本数、一致数、拿不准、跳过和主要混淆分类。“暂无已回答样本”不算检查失败，也不代表分类准确。关闭、预算等待、依赖故障各有自己的状态。结果只代表这批样本，回放仍以原决策时间为证据边界，不使用后来学到的信息。
