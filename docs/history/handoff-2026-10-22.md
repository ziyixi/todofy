## Tasks UI refinement, released

Implementation `6ef11633809bfefc2b2a4602bc71a53dbe1a7c2a`, branch `codex/tasks-design`, was based on
`43eb37bb` in `/private/tmp/todofy-tasks-design`. The owner's shared checkout was left untouched to avoid
conflicting with ongoing work.

- The compact Focus timer keeps the Step title, visible controls and cumulative time against the estimate.
  Taller windows show the parent outcome. It uses existing tokens and Lucide icons; the main timer bar's clock
  is slightly stronger. No new dependency, timer state or server requests.
- Save displays a check and Saved without moving the dialog. Description Done saves the current complete draft
  through the existing write, keeps it on failure and renders Markdown immediately. The existing renderer is
  eager so a cached reopen does not swap raw text for Markdown. Pending title/description input is disabled.
- Quick respects the Deadline start window as well as its existing Due selection. Zero lead opens on Deadline
  day; otherwise eligible active work remains available.
- Plan's Step estimate panel deletes a Step with inline confirmation through native DeleteTask. Existing
  queue/dependency deletion semantics and time records are retained.

The [rendered review](../../tasks/docs/ui-refinement.md) contains the design findings, screenshots and scope.
No schema, real task, stored history, resource, credential, budget or processing switch was changed.
