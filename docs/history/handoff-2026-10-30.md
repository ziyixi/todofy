## Newsletter console SQLite and morning model failure

uses SQLite 3.40.1: its first `json_each` virtual-table declaration triggered a schema-write authorization event,
which the console's read-only authorizer refused. The Bazel interpreter's newer SQLite did not reproduce it.

unchanged synthetic database bytes. Existing HTTP/SDK checks remain; no model, prompt, budget or retry behavior changed.
