## Full Bazel migration

The complete migration is in [PR #10](https://github.com/ziyixi/todofy/pull/10). Application roots produce compiled
Worker/UI archives, Linux images, independent extension ZIPs and the prepared-content website. Shared proto generation,
original checks, import-based libraries and fixed third-party/toolchain inputs run through Bazel. Actions keeps credentials,
publication locks, dependency order, persistent identities and live verification.

The native graph selects affected leaf checks and actual release inputs. Test-only changes keep publications separate;
VPS resume excludes image actions. Publishers promote compiled bytes. Retired path maps/check Actions, duplicate generators,
custom pytest shards/merger and Dockerfile build paths were removed.
